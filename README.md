# Eco-Calculator: расчёт срока службы школьной формы

Проект для школьного экологического проекта: калькулятор, который показывает, как уход за вещами влияет на их срок службы.

## Что внутри

- `calculator.py` — логика расчёта на Python: базовый ресурс вещи минус штрафы за частую/горячую стирку плюс бонусы за бережный уход.
- Реализован сценарий «было 3 месяца → стало 12 месяцев» для наглядности.

## Как запустить

1. Скачай `calculator.py`.
2. Запусти в любой среде для Python (IDLE, PyCharm, VS Code, Google Colab).
3. В консоли увидишь расчёт срока службы при разных режимах ухода.

## Связь с веб-версией

Логика из Python перенесена в JavaScript для веб-калькулятора (HTML/CSS/JS), чтобы расчёт работал прямо в браузере.
